# Aureveil Studios Invitation Demo

A simple static website for a premium tap-to-open wedding invitation experience.

Open `index.html` or deploy this repository with GitHub Pages. The main demo is `demo.html`: it shows a solid paper gatefold invitation cover, opens on tap, then transitions into a swipeable mobile wedding invitation with countdown, event details, map/share links, music toggle, and RSVP mockup.

See `DESIGN_DIRECTION.md` for the updated Aureveil Studio visual direction, PNG export specs, and animation notes.

See `UPDATE.md` and `product-update.html` for the current product strategy, architecture, packages, and launch priorities.
