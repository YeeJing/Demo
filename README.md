# Frosted Vellum Invitation Demo

A simple static website for a premium tap-to-open wedding invitation cover.

Open `index.html` or deploy this repository with GitHub Pages. The cover shows a frosted vellum envelope by default; tapping opens the flap and raises the inner invitation card.

See `DESIGN_DIRECTION.md` for the updated Aureveil Studio visual direction, PNG export specs, and animation notes.

See `UPDATE.md` and `product-update.html` for the current product strategy, architecture, packages, and launch priorities.
